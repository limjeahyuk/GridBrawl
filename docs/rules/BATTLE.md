## ① 한 줄 요약

**1:1 카드 전투 로그라이크.** 6×4 격자에서 두 파이터가 마주 서고, 한 라운드에 카드 3장을 골라 슬롯 1→2→3 순서로 동시에 실행한다. 직업을 골라 지도 두 장(1막 초원 20층 → 2막 던전 20층)을 오르며 덱과 유물을 키우고 막마다 보스를 잡는다.

### 용어 — 턴 ≠ 라운드
| 말 | 뜻 | 코드 |
| --- | --- | --- |
| **턴** | 양쪽이 카드를 한 장씩 내는 것 | `slot` 0·1·2 |
| **라운드** | 카드 3장을 고르고 다 쓰는 것 = 3턴 | `BattleState.round` · `resolveRound` |

쿨타임 · 상태이상 지속 · 보호막 · 붕괴는 **전부 라운드 단위**다. ⚠ 유물 훅 `turnEnergy`/`turnShield`는 이름만 "turn"이고 실제로는 라운드마다다.

## ② 판

- **격자 6열 × 4행**(`GRID_COLS`·`GRID_ROWS`). 셀 `{ col, row }`, col은 오른쪽 · row는 아래로 는다.
- **시작 자리**: PvP는 양 끝 row 1 고정(`START_CELLS`). **런은 자기 끝열 네 칸 중 무작위**(`BattleOpts.startCells`), 보스만 row 1 고정.
- **방향은 위치로 정한다**(`facingBetween` 한 곳). 같은 열이면 좌석(side)으로.
- **겹침 허용** — 두 파이터는 같은 칸에 설 수 있다. 겹친 상대를 맞히는지는 카드의 `pointBlank`(기본 맞힘, `false`면 못 맞힘)로 판정한다.
- 공격 사거리 `range`는 오프셋 `{ df, du }` 목록(df = 앞 +, du = 위 +)이고 **대부분 앞뒤 대칭**이다. 헬퍼: `fwd` · `beam` · `both` · `beamBoth` · `bar` · `barBoth` · `CROSS` · `FORK` · `RING`(`roster.ts`).

## ③ 라운드 진행

1. 양쪽이 카드 3장을 고른다(덱 = 손패, 셔플·드로우 없음).
2. 라운드 시작: 보호막 리셋 → **기력 +10**(`ENERGY_REGEN`, 최대치 cap) → 패시브(라운드마다 기력·보호막·체력).
3. **슬롯 1 → 2 → 3.** 한 슬롯 안에선 두 카드를 **이동 < 수비 < 공격** 순으로 처리한다(전역 묶음이 아니라 같은 슬롯 안의 우선순위).
4. **같은 공격 카드는 라운드에 한 번**(UI·AI가 막고, 보스 스크립트도 지킨다 — `npm run check`).
5. 라운드 끝: 독안개 · 붕괴 · 불길 피해, 상태이상 지속 차감, 쿨타임 차감.

### 같은 슬롯의 맞교환
- 양쪽 공격은 **같은 판에서 계산**하지만 **쓰러뜨리는 쪽부터 적용하고, 쓰러진 쪽은 못 때린다.** 진짜 동시 KO만 예외 — 라운드 시작 HP 비율로 승자를 가린다.
- 한쪽만 상대를 밀어내면 밀려난 쪽의 공격은 **새 자리에서 다시 겨눈다**(닿느냐만 바뀌고 수치는 그대로). 서로 밀면 재판정 없음.
- 넉백이 벽·바위에 막혀 **처박혀 기절**하면 그 슬롯의 반격도 막힌다(기절 스텝이 된다 · 2026-11-10 · `RULES_VERSION` 7). 넉백 없는 기절끼리의 같은 슬롯 맞교환은 여전히 동시.

### 넉백 3원칙(사용자 확정)
상대가 내 오른쪽 → 오른쪽으로 / 왼쪽 → 왼쪽으로 / **같은 칸 → 오른쪽으로**. ③은 임시 폴백이 아니다.
- **처박기**: 벽·바위에 막혀 못 간 칸당 피해 5(`KNOCKBACK_BLOCK_DAMAGE`) + 기절 1(다음 턴까지 · 2026-11-13). 부분 차단도 기절. 처박기 기절은 연장 유물을 안 탄다.

## ④ 카드

### 종류(`CardKind`)
`move` · `attack` · `guard`(수비) · `energy`(기력) · `heal`(회복) · `buff`(강화). 모든 카드에 `cooldown`(라운드).
- **이동**: 직교 4 · 대각 4 · 대시(좌우 2칸). 이동은 **판의 칸을 눌러서** 한다 — 호박색 칸은 덱의 이동 카드로 만들어지고, 손패에선 **이동 묶음 한 장**(`MoveBundle`)으로 접힌다.
- **버프**: `atkUp`(공격 +) · `defUp`(받는 피해 −) · `freeCast`(기력 0으로 쓰기). ⚠ `freeCast`는 엔진 `costOf` · UI `planAffordable` · AI 예산 세 곳이 같아야 한다(`baseCostOf`).

### 능력 필드(`CardDef`, 조합 가능)
| 필드 | 효과 |
| --- | --- |
| `drain` | 적중 시(막혀도) 상대 기력 N 흡수 |
| `leech` | 실제로 뚫은 피해가 있으면 체력 N 회복 |
| `pierce` | 보호막을 무시하고, **바위도 뚫는다** |
| `push` / `pull` | 넉백 N / 끌어당기기 N |
| `selfShield` / `recoil` | 기력을 낸 순간 자기 보호막 +N / 체력 −N(빗나가도) |
| `stun` · `freeze` · `bind` | 기절 · 빙결 · 속박(그 라운드) |
| `poison` · `burn` | 중독 **N겹**(2026-11-12 개편) · 화상 **N겹**(2026-11-13 개편) |
| `fog` | 독안개 칸 N라운드 |
| `shatter` | 보호막을 남김없이 부순다 |
| `empower` | 힘 +N(전투 내내) |
| `dashForward` | 이동공격 — 바라보는 쪽으로 N칸 돌진 후 타격 |
| `raiseRocks` | 바위를 세운다(지형 카드 · 수호기사 「석벽 소환」) |
| `pointBlank: false` | 겹친(밀착) 상대를 못 맞힌다 |
| `legend` | 표시 전용 — 금빛 테두리 · "전설" 띠(「세계수의 가호」) |

능력의 뜻(칩 · 설명)은 `ui/cardAbility.ts` 한 곳에서 정한다.

## ⑧ AI (`battle/ai.ts`)

- 몬스터 성격 `behavior`: `rusher`(파고든다) · `kiter`(간격 2를 지키며 쏜다) · `turtle`(가드하며 기다린다) · `skirmisher`(줄을 옮겨 견제) · `balanced`. 걸음(`gait`) · 전투별 기분(`moodAgg` ±0.12). 접근은 대각 포함.
- 슬롯마다 조준점을 다시 잡는다(난이도별 `CLOSE_IN`). **런 난이도가 플레이어 계획을 얼마나 읽는지 정한다** — 초급 0장 · 중급 1장 · 고급 3장 · 최고급 3장 + 대응(라운드를 훔치는 카드 — 피해 24↑(`THREAT_DAMAGE`) 또는 봉인기 — 를 라운드에 한 번 막거나 피함). 공격이 안 오는 라운드엔 가드를 안 든다.
- 보스는 스크립트 패턴(예고 포함) — [RUN.md](RUN.md) ⑧.
