## 용어 — 턴 ≠ 라운드 (CLAUDE.md §1)

- **턴** = 양쪽이 카드 한 장씩(슬롯 하나). **라운드** = 3턴.
- 원문은 "턴"으로 적혀 있고 그대로 읽는다 — 화염 **9턴 = 3라운드**(지금 불길 3라운드와 같다), 독안개 5턴 = 1라운드 + 2턴.
- "턴이 끝날 때" = 그 슬롯의 이동 · 수비 · 공격을 다 치른 뒤.

## 1. 바위

| 항목 | 규칙 |
| --- | --- |
| 서기 · 지나가기 | **못 선다 · 못 지나간다**(이동 · 대시 · 넉백 · 끌어당김이 바위 앞에서 멈춘다 — 지금과 같다) |
| 공격 | **막지 않는다** — 바위는 이동만 막고, 같은 줄 · 열 너머의 상대도 그대로 맞는다(지금은 사격선을 끊는다 → 바뀜). 그래서 "관통이 바위를 무시"도 뜻이 없어진다 |
| 처박기 | 밀격으로 바위에 막히면 **추가 피해 + 기절**(지금 처박기 규칙 — 못 간 칸당 5 + 기절 1) |
| 체력 | **999** — 깨지 말라고 둔 값이다(사실상 안 깨진다) |
| 상태이상 | **모든 상태이상 면역**(화상 · 속박 · 기절 등 — 지금과 같다) |
| 깨지면 | **그냥 기본 지형**(빈 칸)이 된다 |

| 항목 | 규칙 |
| --- | --- |
| 걸림 | 덩굴 칸에 **들어서면 속박 1턴** |

## 3. 화염 지형

| 항목 | 규칙 |
| --- | --- |
| 서 있으면 | **턴이 끝날 때마다 피해 10 + 화상 1겹** — 계속 서 있으면 턴마다 1겹씩 쌓인다(세기는 3겹에서 멈춤) |
| 지나가면 | **피해 5**만 받고 끝(대시로 지나쳐도, **밀려서 지나가도** 5를 받고 도착 칸에 선다) |
| 도착하면 | 그 턴이 끝날 때 **피해 10 + 화상 1겹**만(들어설 때 따로 아프지 않다) |
| 보호막 · 경감 | 피해 10 · 5를 **보호막과 받는 피해 감소가 막는다**. **일부라도 체력에 닿으면 화상 1겹**, 다 막으면 화상도 없다 |
| 지속 | **9턴 뒤 사라진다** |
| 덩굴 | 붙은 덩굴을 다음 라운드에 화염으로 바꾼다(2절) |

| 항목 | 규칙 |
| --- | --- |
| 지나가기 | 문제없다 |
| 언제 빠지나 | **구멍 칸에 멈춘 바로 그때**(이동 도착 · 넉백으로 밀려 멈춤 · 서 있던 균열이 구멍이 됨) |
| 빠지면 | **빠진다** → **피해 50** + 구멍과 면이 맞닿은 칸(**상하좌우) 중 무작위 한 칸, 25%씩**으로 나온다(Q10 — 고르는 화면 없음) |
| 나올 칸이 막힘 | 판 밖 · 바위 · 다른 구멍 쪽은 빼고 **남은 칸끼리 같은 확률**. 상대가 선 칸으로는 나올 수 있다(겹쳐 설 수 있다) |
| 다 막혔으면 | **그 자리에서 쓰러진다** — 적이면 내 승리, 내가 그러면 게임 오버 |
| 3단계에서 | 3단계 균열 위에 서 있다가 구멍이 되면 **바로 빠진다**(피해 50 + 무작위 칸) |

## 6. 빙판 지형

- 빙판 위에서 **무슨 행동을 하든**(지나가기 · 도착 · 공격 · 수비 · 회복 · 이동) **30% 확률로 넘어진다** → **기절 1턴**.
- 빙판 **칸마다 따로** 30%(대시로 두 칸을 지나면 두 번 굴린다). 영웅 · 몬스터 같은 확률.
- **넘어지면 빙판이 사라진다.** 안 넘어지면 남는다.
- 기절 1턴 = **넘어진 그 턴도 기절이고, 다음 턴까지**(Q13 — 봉인 규칙 "건 턴 다음부터 N턴"과 같다). 즉 그 턴의 행동이 취소되고 다음 턴도 못 낸다. 이동 · 대시로 도착하다 넘어지면 거기까지 간 뒤 다음 턴이 기절이다.

| 하는 일 | 넘어지면(30%) |
| --- | --- |
| 대시로 빙판을 지나칠 때 | **빙판 위에서** 기절 1턴(거기서 멈춘다) |
| 이동해서 빙판에 도착 | 빙판 위에서 기절 1턴 |
| 빙판 위에서 공격 · 수비 · 회복 등 | **행동이 취소**되고 기절 1턴 |
| 빙판 위에서 다른 칸으로 이동 | **이동이 취소**되고 빙판 위에서 기절 1턴 |

## 7. 위험 지형 (추후 카드용)

- 추후 "1턴 뒤에 공격한다" 같은 카드를 넣을 때 쓴다 — **여기에 무언가 떨어진다**를 보여 주는 칸.
- 그냥 칸에 **반투명한 빨간색**. 규칙은 그 카드를 만들 때 정한다(지금은 표시만).

## 8-bis. 전장 붕괴 — 없앤다 (Q4)

- 6라운드부터 가장자리 열이 무너지던 규칙(`collapseRound` · `isCollapsedCell` · 안전지대 · 엘리트 · 보스 지연 · 피해 5/8/12)을 **통째로 없앤다**. 시간이 지나면서 지형이 망가지는 규칙은 없다 — 사용자가 추후 다른 것으로 다시 생각한다.
- 같이 없어지는 것: 붕괴로 빙결이 깨지는 규칙 · 첫 만남 팁 "6라운드 붕괴" · AI의 붕괴 회피 · `BattleOpts.collapseDelay`.
- 붕괴에 기대던 유물 4종(무쇠 신발 · 고정 말뚝 · 허공 걸음 · 세계의 기둥 — `collapseResist`)은 **구멍에 빠진 피해 감소**로 돌린다(-4 · -7 · -12 · 무시, 문구 "무너진 칸" → "구멍"). **임시** — 사용자가 추후 재정의한다.
- ⚠ 판이 좁아지지 않아 **전투가 끝나지 않을 수 있다** — 그래서 아래 8-quater(T20)를 넣는다.

## 8-quater. 전투를 끝낼 장치 — 구멍이 생긴다 (T20 · 2026-11-13)

- 사용자가 안 정한 곳은 **임시값**으로 정했다(아래 표 — 다르면 고친다).

| 항목 | 임시값 | 왜 |
| --- | --- | --- |
| 개수 | 한 번에 **2칸**(`HOLE_SPAWN_COUNT`) | 24칸 판에서 10 · 15 · 20라운드에 2 · 4 · 6칸 — 설 자리가 눈에 띄게 줄되 한 번에 판이 막히진 않는다 |

| 전투 | **모든 전투**(일반 · 엘리트 · 보스 · 고블린 · 이벤트) · 엘리트 · 보스도 같은 라운드 | 옛 붕괴의 "엘리트 · 보스 4라운드 늦게"는 이걸로 옮기지 않았다(난이도 볼 때 정한다) |

| PvP | 런 전용(`BattleOpts.seed`가 있을 때만) — PvP는 main에 없고, 되살리면 그때 정한다 | |
