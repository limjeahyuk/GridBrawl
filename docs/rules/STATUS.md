## 0. 지금 코드 — 한눈에 (2026-08-07 재정의 · 11-12 ~ 11-13 개편 반영)

| 상태이상 | 언제 아픈가 | 수치 | 지속 |
| --- | --- | --- | --- |
| 중독 | 행동 한 번마다 — 이동 카드 1장(몇 칸이든 · 0칸이면 안 아픔) / 공격 카드 1장(빗나가도 · 이동공격 합쳐서) / 밀려나거나 끌려감 | **지금 겹 × 1** · 보호막 · 경감 관통 | **겹 = 남은 라운드**(라운드 끝 −1) · 한 칸 · 상한 없음 |
| 화상 | **카드 공격**에 맞을 때마다 | 보호막 전 피해 +10 / 20 / 30%(1 / 2 / 3겹~) · 보호막 · 경감이 막는다 | 겹 = 남은 라운드 · 한 칸 · 상한 없음 |
| 빙결 | 그 턴 카드 못 냄 · **피해를 받으면 깨진다**(카드 공격 · 처박기 · 붕괴 — 깨지면 늘 +5) | | **건 턴 다음부터 N턴**(카드 · 유물 1) · 라운드를 넘어감 |
| 기절 | 그 턴 카드 못 냄 | | 〃 · 처박기 = 기절 1 |
| 속박 | 그 턴 이동 카드만 무효 | | 〃 |
| 독안개(칸) | 라운드 끝에 서 있으면 | 10 · 보호막 무시 | N라운드 |
| 힘(`empower`) | 내 모든 공격 | +N | 전투 내내 |

- **중독**(2026-11-12 개편 · 1절): 카드 · 유물의 `poison: N` = **N겹**. 한 대에 여러 곳이 걸면 **다 더한다**(카드 + `poisonOnHit` + 안식일 `poisonRoundBonus`). 위력 % = 거는 쪽(상대)의 `statusPowerPct`로 **아플 때** `round(겹 × (1 + %/100))`. 궁수 직업 패시브의 중독은 없앴다(공격 +5 · 받는 피해 −2만).
- 화상(2026-11-13 개편 · 2절): `burn: N` = N겹, 카드 + 유물 + 안식일을 더한다. 세기는 보호막 전 `raw`에 곱하고 반올림, 늘어난 몫도 보호막 · 경감이 막는다. 위력 % 유물은 중독 전용. 불길 함정은 임시 1겹. 출혈은 3절에 확정 · 미구현.
- **이동불가**(빙결 · 기절 · 속박 — 2026-11-13 개편 · 4절): 숫자 N = **건 턴 다음부터 N턴**, `rounds`가 "지금 턴 뒤로 남은 턴"이고 **슬롯 시작마다 1씩** 준다(라운드 끝 정산을 안 탄다 → 라운드를 넘어간다). 같은 슬롯의 상대 공격은 그대로 나간다(처박기만 같은 슬롯 반격을 막는다). 다음 라운드로 넘어간 기절 · 빙결 턴은 **카드를 고를 때 그 슬롯이 잠긴다**(`freshSlots` 자리표 — 제출할 때 비워 보낸다). 속박 턴 슬롯엔 **이동 카드만 못 넣는다**(`moveBound` — 다음 빈 슬롯이 속박 턴이면 이동 칸 · 묶음이 닫힌다). AI는 잠긴 슬롯을 비우고 **풀린 첫 턴엔 무조건 피하거나(이동) 막는다(가드)**. 속박 턴엔 이동 없이 공격 · 수비만 하고, 속박이 끝난 턴에 이동한다. 봉인이 풀리자마자 다시 맞으면 새 봉인이 새로 시작한다(남은 0인 봉인은 겹치기 판정에서 빠진다 — 사용자 확인 11-13).
- **겹치기**: 속박 < 기절 < 빙결(`LOCK_RANK`). 봉인 중(남은 턴 > 0)엔 **더 높은 것만** 얹히고 같은 것 · 낮은 것은 안 걸린다. 얹힌 봉인은 **처음 걸린 봉인의 남은 길이**를 넘지 않는다. 빙결 중에 맞은 타격은 빙결만 깨고 새 봉인을 안 건다 — 깨지면 밑의 기절 · 속박이 남은 턴만큼 이어진다. 연장 훅(`*RoundBonus` — 이름만 옛것, 값은 턴)은 유물에만(「얽매는 뿌리」 속박 +2 · 임시).
- ⚠ **무한 봉인을 막는 건 `applyStatus`의 겹치기 규칙**(옛 "재부여 가드"를 대신한다). 풀면 연장 유물이 "영원히 못 움직임"이 된다.
- ⚠ 연장 훅 다섯(`poisonRoundBonus` 등)은 유물에만 — 직업 패시브(PvP) · 몬스터에 넣지 말 것.
- ⚠ 흡혈 · 반사 · 기절 · 부여는 `core`(보호막 · 경감을 실제로 뚫은 몫)를 본다. 빙결 파쇄(관통) 몫으로 켜면 가드가 무의미해진다. 화상으로 늘어난 몫은 보호막이 먼저 받으므로 `core` 안에 든다(2026-11-13).
- **회복량 %(`healPowerPct`)는 회복 카드에만 붙는다** — 매 라운드 체력 회복(`regen`)은 적힌 값 그대로다(2026-11-12 사용자 지정 — 세계수의 가지 +10이 30이 되던 것).
- `tickStatuses`는 피해를 안 준다 — 라운드 끝에 갉는 건 독안개 · 붕괴 · 불길(화상 부여)뿐.
- 런 전용 훅 `burnImmune`(화상 면역 — 「타오르는 알」 · 「불사조의 깃털」)은 엔진 `applyStatus`가 본다.

## 1. 중독 (확정 · **구현됨 2026-11-12**)

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹(중첩) 수 하나**로 센다. 걸 때마다 더해지고 **상한은 없다** — 오래 붙어 겹을 잘 쌓은 궁수가 이기는 게 맞다(사용자 확인) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다** → 5겹이면 5라운드가 끝나야 사라진다. 따로 "남은 라운드"는 없다 |
| 언제 아픈가 | 아래 "한 번"마다 **지금 겹 수 × 1** 피해 |
| 피해 성질 | 보호막 · 받는 피해 감소(유물 · 방어 강화)를 **관통**한다. 이 피해로 쓰러질 수 있다 |
| 걸리는 조건 | 지금과 같다 — 공격이 보호막·경감을 **실제로 뚫은 피해**가 있을 때만. 보호막이 다 받아 내면 안 걸린다 |
| 마지막 슬롯 | 3번 슬롯에서 1겹을 걸면 라운드 끝에 바로 줄어 사라진다(의도) |

예: 4겹일 때 움직이면 4 → 그 라운드 끝에 3겹 → 다음 라운드에 움직이면 3.
예: 3겹 · 보호막 20 · 체력 30에서 움직이면 체력 27(보호막 그대로). 그때 상대의 중독 카드(피해 10)가 보호막 20에 다 막히면 중독은 안 늘어난다.

### 유물

중독을 다루는 유물 9종(독약 플라스크 · 맹독 병 · 재의 폐 · 부패의 왕관 · 동사의 저주 · 마녀의 안식일 · 사악한 절구 · 한파 · 마녀의 탕약)의 문구 · 수치는 [RELICS_100.md](RELICS_100.md) 0-7이 기준이다. 훅의 뜻: `poisonOnHit: N` = 맞힐 때 N겹 · `poisonRoundBonus`(안식일) = 걸 때마다 +1겹 · `statusPowerPct` = 아래 "위력 %".

- **한 대에 여러 곳이 걸면 다 더한다**(카드 + 유물 + 안식일 · 사용자 확인). 예: 독니 화살 2 + 맹독 병 2 + 안식일 1 = 5겹.
- **위력 %**: 중독 피해 = `round(겹 × (1 + %/100))` — **아플 때** 계산하고 반올림한다(사용자 확인 · 겹이 하나의 수라 거는 순간에 박아 둘 곳이 없다). 거는 쪽(상대)의 유물을 본다. 예: 절구 +40% — 1겹 1 · 2겹 3 · 3겹 4 · 5겹 7.
- **위력 % 유물은 중독에만 붙는다** — 화상 · 출혈엔 안 붙는다(2026-11-12 사용자 지정). 그래서 절구 · 한파 · 탕약 · 왕관 문구에서 "화상"이 빠진다.
- 「차가운 쇠」 · 「뼈 발라내기」 · 「사냥꾼의 앙심」 등 "상태이상 상대에게 +N"은 그대로(중독 1겹 이상이면 걸린 것 · 출혈도 센다 — 3절).

### 밸런스

옛 규칙(겹당 3 · 최대 3겹 → 행동당 최대 9)과 크게 다르다. 궁수 직업 패시브 중독도 빠졌다. **구현하면서 나중에 맞춘다**(사용자 지정).

## 2. 화상 (확정 · 2026-11-12 사용자 지정 · **구현됨 2026-11-13**)

**옛 규칙과 다르다** — 옛 화상은 "맞을 때마다 겹당 +5 · 보호막 관통"이었다. 새 화상은 **카드 공격의 피해를 % 늘리고, 늘어난 몫도 보호막이 막는다.**

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹 수 하나 · 상한 없음**(중독과 같다) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다**(중독과 같다) |
| 무엇을 하나 | **카드 공격**에 맞을 때 그 피해가 늘어난다 — **1겹 +10% · 2겹 +20% · 3겹 이상 +30%**(늘어나는 몫의 상한 30%). 겹은 계속 쌓여 오래 가지만 세기는 3겹에서 멈춘다 |
| 어디에 곱하나 | **보호막 전 카드 피해** = 카드 피해 + 공격 보너스(유물 · 직업) + 힘 + 공격 강화를 다 더한 값(지금 코드의 `raw`)에 곱하고 **반올림**한다 → 그 뒤에 보호막 · 받는 피해 감소 |
| 안 붙는 것 | 카드 공격이 아닌 피해 — 중독 · 출혈 몫 · 처박기 · 독안개 · 붕괴 |
| 피해 성질 | **보호막을 뚫지 못한다**(늘어난 몫까지 보호막이 받는다) |
| 걸리는 조건 | **체력이 닳아야** 걸린다(공격이 보호막 · 경감을 실제로 뚫은 피해가 있을 때만 — 지금과 같다) |
| 위력 % 유물 | **안 붙는다**(절구 · 한파 · 탕약 · 왕관은 중독 전용이 된다) |
| 늘어난 몫과 부여 | 화상으로 늘어난 몫까지 보호막을 넘어 **체력이 닳으면** 그 타격의 상태이상 · 기절 · 흡혈이 걸린다(2026-11-13 사용자 확인) |

예: 화상 1겹 · 피해 7 → `round(7.7)` = 8. 화상 5겹이어도 +30%.

## 4. 이동불가 상태이상 — 속박 · 기절 · 빙결 (확정 · 2026-11-12 사용자 지정 · **구현됨 2026-11-13**)

**옛 규칙과 다르다** — 옛 셋은 "건 라운드만 · 라운드 끝에 사라짐 · 숫자는 뜻 없음(`>0`)"이었다. 새 규칙은 **숫자가 턴 수**이고 **라운드를 넘어간다.** 셋을 묶어 **이동불가 상태이상**이라 부른다.

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 숫자 | **건 턴 다음부터 N턴**(턴 = 슬롯 하나). 속박 1 = 건 턴 + **다음 턴까지**. 한 슬롯 안은 이동 → 수비 → 공격 순이라 공격으로 건 봉인이 닿을 땐 상대의 그 턴 이동 · 수비는 이미 끝났고, **같은 슬롯에 낸 상대 공격도 그대로 나간다**(지금처럼 트레이드 — 처박기만 예외, 아래). 그래서 숫자는 "다음 턴부터"를 센다(사용자 — "말이 1인데 지금의 2와 같은 효과") |
| 지속 | 턴이 끝날 때마다 1씩 줄고 0이면 풀린다. **라운드가 끝나도 이어진다** |
| 무엇을 하나 | 이전과 같다 — 기절 · 빙결 = 그 턴에 카드를 못 냄 · 속박 = 그 턴의 이동 카드만 무효 |
| 넘어간 봉인 | 다음 라운드로 넘어간 기절 · 빙결 턴은 카드를 고를 때 **그 슬롯이 잠긴다**(카드를 못 넣는다). 속박 턴 슬롯엔 **이동 카드만** 못 넣는다(2026-11-13 사용자 지정) |
| 풀리자마자 또 | 봉인이 끝나는 턴(남은 0)에 다시 맞으면 겹치기가 아니라 **새 봉인으로 새로 시작**한다 — 풀리자마자 맞는 건 막지 않은 대가(2026-11-13 사용자 확인) |
| AI | 잠긴 슬롯은 비우고, **풀린 첫 턴엔 무조건 피하거나(이동) 막는다(가드)**(2026-11-13 사용자 지정). **속박 턴엔 이동 없이 공격 · 수비만** 하고 속박이 끝난 턴에 이동한다(같은 날 사용자 지정). 최고급의 봉인기 대응은 추후 |
| 겹치기 | **속박 → 기절 → 빙결 순으로 위에 얹힌다**(아래 "겹치기" 표). 얹혀도 **가장 처음 걸린 봉인의 턴 수가 끝까지 간다** — 전체 길이는 안 늘어나고, 새 봉인의 턴은 남은 길이에서 잘린다 |
| 빙결 깨짐 | 빙결은 **카드 공격 · 처박기 · 붕괴 피해**를 받으면 풀리고, **깨지면 늘 +5**(2026-11-13 사용자 지정 — 붕괴로 깨져도). **독안개 · 중독으로는 안 깨진다**. 빙결 중 속박 · 기절 · 빙결 공격을 맞으면 **빙결만 깨지고 새 봉인은 안 걸린다**. 깨져도 **밑에 깔린 기절 · 속박의 턴이 남았으면 그 상태로 돌아간다** |
| 처박기 | 넉백이 벽 · 바위에 막히면 **기절 1**(= 다음 턴까지 — 사용자 "딱 다음 턴까지만"). 칸당 5 피해 · 같은 슬롯 반격이 막히는 것(2026-11-10)은 그대로 |
| 걸리는 조건 · 전투당 횟수 | 이전과 같다(체력이 닳아야 걸림 · 유물 "전투당 N번") |

예: 1라운드 3턴에 내가 **기절 3** 성공(숫자가 "다음 턴부터"라 사용자가 처음 든 예보다 한 턴 길다)
