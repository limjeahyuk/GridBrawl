# ? 이벤트 목록

**새 이벤트는 이 파일 맨 아래 [틀](#새-이벤트-틀)을 복사해서 적는다.** 같은 내용이 `events.json`에 데이터로도 있다. 둘을 함께 고치거나, Claude에게 "EVENTS.md에 추가한 이벤트 반영해줘"라고 하면 된다.

시안 화면:

- `screens/EventsQ.dc.html`: 플레이어 화면. 탭으로 이벤트를 바꿔 가며 직접 골라 볼 수 있다.
- `screens/EventCatalog.dc.html`: 개발용 한눈 보기. 숨은 결과까지 적혀 있다.

그림은 `public/redesign/ui/events/`에 있다(×4로 쓴다). 뱀은 `public/redesign/sprites/snake/`에 있다.

## 공통 규칙 (모든 이벤트)

1. **선택지에는 "대가"만 보인다.** `라벨 / 대가 - 결과`에서 `- 결과`는 **화면에 절대 안 나온다.** 고른 뒤 결과 패널에서 처음 공개된다.
   - 대가 칩: 골드 `50G`(금색) · `HP -10`(빨강) · `최대 HP -10`(분홍) · `카드 1장`/`유물 1개`(회색)
   - 대가가 없는 선택지는 칩도 없다.
2. **히든 선택지는 잠금 아이콘으로 잠근다.**
   - 조건을 채우기 전: 자물쇠 + `???` + "잠겨 있다 — 무언가 필요해 보인다". 빗금 배경, 누를 수 없다. 무엇이 필요한지는 말하지 않는다.
   - 조건을 채운 뒤: 열린 자물쇠 + 진짜 라벨 + 금색 테두리 + "히든 · ○○이 있어서 열렸다".
3. **반복 이벤트**(약방 · 갓챠 · 두더지): 결과 뒤에 "계속하기"가 나온다. 그만두려면 선택지의 나가기를 고른다. 끝나는 조건을 채우면 자동으로 나간다.
4. 확률은 화면에 보여 주지 않는다. 갓챠는 "기계가 조금 헐거워진 것 같다", 두더지는 "다시 파면 더 힘들다"처럼 분위기로만 알려 준다.
5. 받는 유물은 결과 패널에 아이콘(×3)과 이름, 설명으로 보여 준다. 처음 얻는 유물은 도감에 등록한다.

## 유물 풀 (이벤트가 "○○ 관련 유물"을 줄 때)

이미 있는 유물(`relics.ts`)에 태그를 단다. 풀에서 무작위로 하나를 주되, 이미 가진 건 뺀다.

| 태그 | 유물 |
| --- | --- |
| `iron` 쇠 | 두꺼운 판금 · 무쇠 신발 · 단단한 손잡이 · 강철 의지 · 탑 방패 · 가시 방패 · 가시 갑옷 |
| `poison` 독 | 독약 플라스크 · 맹독 병 · 마녀의 탕약 |
| `heart` 심장 | 심장 강화 · 황소 심장 · 거인의 심장 · 잿불 심장 |
| `hand` 손 | 동상의 손 · 처벌자의 손 · 황금손 · 연쇄 벼락 |
| `foot` 발 | 무쇠 신발 · 고정 말뚝 · 허공 걸음 |
| `any` 아무거나 | 등급 규칙대로 무작위 |

`차가운 쇠`(`coldiron`)는 이미 있는 일반 유물이다.

## 1. 대장장이 `EV-FORGE` · 한 번 · 그림 `forge.png`(64×52, 6프레임)

빈 대장간을 발견했다. 신기하게 불은 꺼질 생각을 하지 않는다.

- 카드라도 두들긴다 - 카드 강화(룰렛 강화 화면으로)
- 주변에 쇠라도 챙긴다 - 유물 「차가운 쇠」 얻기
- 🔒 **히든** · 조건: 「차가운 쇠」 보유
  - 쇠를 두들긴다 - 「차가운 쇠」를 잃고 `iron` 유물 하나(무작위)

## 2. 거래 `EV-TRADE` · 한 번 · `trader.png`(52×60)

"그 물건 탐나는군요. 저와 거래하실래요?" 누군가가 거래를 요청했다.

- 내 카드 한 장 ↔ 다른 카드 / 카드 1장 - 내 카드 하나를 고르면 무작위 카드 하나를 받는다
- 내 카드 한 장 ↔ 유물 / 카드 1장 - 내 카드 하나를 고르면 무작위 유물 하나를 받는다
- 내 유물 하나 ↔ 다른 유물 / 유물 1개 - 내 유물 하나를 고르면 무작위 유물 하나를 받는다

흐름은 선택지 → 내 카드나 유물 고르기 → 받은 것 공개다. 받을 것은 고르기 전엔 안 보인다.

## 3. 온천 `EV-SPRING` · 한 번 · `hotspring.png`(76×48, 4프레임)

김이 모락모락 나는 아주 뜨끈한 온천을 발견했다. 당장 쉬고 싶어진다.

- 휴식 - 체력 회복(시안: 최대 체력의 30%)

## 4. 약방 `EV-APOTHECARY` · 반복 · `apothecary.png`(72×60), 약 `potion-0~2.png`(12×16)

엄청나게 많은 약들이 있는 약방에 들어섰다. 의문의 남자가 약 3가지를 보여 준다.

- 약(빨강) / 50G - ┐
- 약(초록) / 50G - ├ 셋이 각각 하나씩: 체력 회복(+20) · 체력 감소(-10) · 아무 일 없음
- 약(보라) / 50G - ┘
- 나간다 - 끝

세 병의 효과는 방문할 때마다 섞인다. 같은 약을 또 살 수 있고(중복 가능), 골드가 있는 동안 계속할 수 있다. 골드가 50보다 적으면 약 버튼이 흐려진다.

## 5. 항아리 `EV-JAR` · 한 번 · 전투 · `jar.png`(48×52), 뱀 `sprites/snake`

어둡고 매우 습한 동굴에 들어왔다. 눈앞에 항아리 하나가 떡하니 있다. 열어 보겠습니까?

- 연다
  - 50%: 중독 상태로 동굴 뱀과 전투. 이기면 `poison` 유물 하나.
  - 나머지 50%: 빈 항아리, 아무 일 없음(시안에서 정한 것).
- 건드리지 않는다 - 아무 일 없음

동굴 뱀은 72×40 ×3 크기다. 클립은 idle · run · back · attack1(물기) · attack2(독침) · hurt · death. 체력은 시안에서 34로 정했다.

## 6. 갓챠 `EV-GACHA` · 반복 · `gacha.png`(52×68, 2프레임)

반짝반짝 거리는 가게에 들어서니, 돈을 넣으면 무언가를 집을 수 있을 것 같은 기계가 있다. 해 보겠습니까?

- 돈 넣기 / 50G
  - 당첨 확률은 10%에서 시작해 실패할 때마다 +10%다.
  - 상품은 체력 회복(+25)과 유물(`any`) 두 가지다. 당첨되면 남은 상품 중 하나를 받는다.
  - 당첨되면 확률은 다시 10%부터 시작한다(시안에서 정한 것).
  - 두 가지를 다 뽑으면 "다 뽑은 것 같다…"가 뜨고 자동으로 나간다.
- 나가기 - 끝

돈 넣기 버튼 아래에 "넣은 횟수 N · 남은 상품 N개"를 보여 준다.

## 7. 두더지 `EV-MOLE` · 반복 · `mole.png`(64×44, 4프레임)

반짝거리는 걸 들고 땅으로 들어가는 두더지를 발견했다. 잡을까요?

- 땅 파기 / HP -10
  - 성공 30%에서 시작해 실패할 때마다 +10%다.
  - 성공하면 유물(`any`)을 받고 자동으로 나간다.
  - 팔 때마다 체력 소모가 3씩 는다: 10 → 13 → 16 → … 버튼의 대가 칩 숫자도 함께 바뀐다.
- 가던 길 가기 - 끝

## 8. 수술실 `EV-SURGERY` · 한 번 · `surgery.png`(72×56)

누군가는 강해지기 위해, 누군가는 아름다워지기 위해 이곳을 찾죠. 당신은 무엇을 위해 이곳에 왔나요?

- 심장 / 최대 HP -10 - 최대 체력 10을 깎고 `heart` 유물 하나
- 손 / HP -15 - 체력 15를 깎고 `hand` 유물 하나
- 발 / HP -15 - 체력 15를 깎고 `foot` 유물 하나

  - 선택지 라벨 - 결과

(반복이면) 끝나는 조건 · 확률 변화 · 대가 변화
