## 용어 — 턴 ≠ 라운드 (CLAUDE.md §1)

- **턴** = 양쪽이 카드 한 장씩(슬롯 하나). **라운드** = 3턴.
- 원문은 "턴"으로 적혀 있고 그대로 읽는다 — 화염 **9턴 = 3라운드**(지금 불길 3라운드와 같다), 독안개 5턴 = 1라운드 + 2턴.
- "턴이 끝날 때" = 그 슬롯의 이동 · 수비 · 공격을 다 치른 뒤.

## 1. 바위

| 항목 | 규칙 |
| --- | --- |
| 서기 · 지나가기 | **못 선다 · 못 지나간다**(이동 · 대시 · 넉백 · 끌어당김이 바위 앞에서 멈춘다 — 지금과 같다) |
| 처박기 | 밀격으로 바위에 막히면 **추가 피해 + 기절**(지금 처박기 규칙 — 못 간 칸당 5 + 기절 1) |
| 체력 | **999** — 깰 수는 있지만 사실상 안 깨진다 |
| 상태이상 | 원문 "모든 상태이상" — 뜻 확인 필요(9절 Q2) |
| 깨지면 | **그냥 기본 지형**(빈 칸)이 된다 |

## 2. 덩굴 지형

| 항목 | 규칙 |
| --- | --- |
| 걸림 | 덩굴 칸에 **들어서면 속박 1턴** |
| 지나갈 때 | **덩굴 칸에서 멈추고** 속박에 걸린다 — 남은 이동은 안 한다 |
| 다시 걸림 | 속박이 끝나도 지형은 남는다. **그 자리에 계속 서 있으면 다시 안 걸린다** · **나갔다가 다시 들어오면 또 걸린다** |
| 없애는 법 | 상하좌우(면이 붙은 칸)에 **화염 지형**이 있으면 **다음 라운드에 화염 지형으로 바뀐다**. 대각선은 안 된다 |

예: 앞으로 두 칸 이동하는데 가운데 칸이 덩굴 → 가운데 칸에서 멈추고 속박.

## 3. 화염 지형

| 항목 | 규칙 |
| --- | --- |
| 서 있으면 | **턴이 끝날 때마다 피해 10 + 화상 1겹** |
| 지나가면 | **피해 5**만 받고 끝(대시로 지나쳐도 5를 받고 도착 칸에 선다) |
| 도착하면 | 그 턴이 끝날 때 **피해 10 + 화상 1겹**만(들어설 때 따로 아프지 않다) |
| 보호막 | 피해 10 · 5를 **보호막이 막는다**. 보호막이 다 막으면 **화상도 안 걸린다**(Q5) |
| 지속 | **9턴 뒤 사라진다** |
| 덩굴 | 붙은 덩굴을 다음 라운드에 화염으로 바꾼다(2절) |

## 4. 용암 지형

- **화염 지형과 같다**(서 있으면 턴 끝마다 피해 10 + 화상 1겹).
- 다른 점: **지나가는 건 아무 일 없다** · **절대 사라지지 않는다**.

## 5. 붕괴 지형 → 구멍

### 붕괴 지형(균열)

| 단계 | 모습 | 다음 |
| --- | --- | --- |
| 1단계 | 바닥에 균열 | 누구든 **밟거나 지나갈 때마다** 한 단계 오른다 |
| 2단계 | 균열이 커진다 | 〃 |
| 3단계 | 부서지기 직전 | 한 번 더 밟거나 지나가면 **구멍**이 된다 |

### 구멍

| 항목 | 규칙 |
| --- | --- |
| 지나가기 | 문제없다 |
| 서 있으면 | **빠진다** → **피해 50** + 구멍과 면이 맞닿은 칸(**상하좌우) 중 무작위 한 칸, 25%씩**으로 나온다(Q10 — 고르는 화면 없음) |
| 3단계에서 | 3단계 균열 위에 서 있다가 구멍이 되면 **바로 빠진다**(피해 50 + 무작위 칸) |

## 6. 빙판 지형

- 빙판 위에서 **무슨 행동을 하든**(지나가기 · 도착 · 공격 · 수비 · 회복 · 이동) **30% 확률로 넘어진다** → **기절 1턴**.
- **넘어지면 빙판이 사라진다.**
- 기절 1턴 = **넘어진 그 턴도 기절이고, 다음 턴까지**(Q13 — 봉인 규칙 "건 턴 다음부터 N턴"과 같다). 즉 그 턴의 행동이 취소되고 다음 턴도 못 낸다. 이동 · 대시로 도착하다 넘어지면 거기까지 간 뒤 다음 턴이 기절이다.

| 하는 일 | 넘어지면(30%) |
| --- | --- |
| 대시로 빙판을 지나칠 때 | **빙판 위에서** 기절 1턴(거기서 멈춘다) |
| 이동해서 빙판에 도착 | 빙판 위에서 기절 1턴 |
| 빙판 위에서 공격 · 수비 · 회복 등 | **행동이 취소**되고 기절 1턴 |
| 빙판 위에서 다른 칸으로 이동 | **이동이 취소**되고 빙판 위에서 기절 1턴 |

## 7. 위험 지형 (추후 카드용)

- 추후 "1턴 뒤에 공격한다" 같은 카드를 넣을 때 쓴다 — **여기에 무언가 떨어진다**를 보여 주는 칸.
- 그냥 칸에 **반투명한 빨간색**. 규칙은 그 카드를 만들 때 정한다(지금은 표시만).

## 8. 독안개 지형

| 항목 | 규칙 |
| --- | --- |
| 서 있으면 | **중독 1겹** — **보호막이 있어도 걸린다**(Q5) |
| 지나가면 | 아무 일 없다 |
| 지속 | **5턴**(고정) |
| 퍼짐 | **3턴 뒤 십자로(상하좌우 한 칸) 커졌다가, 2턴 뒤 십자 독안개가 사라진다** |
| 까는 카드 | 「독의 비」(`arc-rain`) · 「역병 화살」(`r-plaguebolt`)은 **그냥 독안개를 깐다**(Q17 — 카드의 숫자 2 · 1은 없앤다, 지속은 위 5턴) |

## 8-bis. 전장 붕괴 — 없앤다 (Q4)

- 6라운드부터 가장자리 열이 무너지던 규칙(`collapseRound` · `isCollapsedCell` · 안전지대 · 엘리트 · 보스 지연 · 피해 5/8/12)을 **통째로 없앤다**. 시간이 지나면서 지형이 망가지는 규칙은 없다 — 사용자가 추후 다른 것으로 다시 생각한다.
- 같이 없어지는 것: 붕괴로 빙결이 깨지는 규칙 · 첫 만남 팁 "6라운드 붕괴" · AI의 붕괴 회피 · `BattleOpts.collapseDelay`.
- ⚠ 붕괴에 기대는 유물 4종(무쇠 신발 · 고정 말뚝 · 허공 걸음 · 세계의 기둥 — `collapseResist`)이 빈 효과가 된다 → 9절 Q20.
