## 흐름

1. **카드 고르기**
   - 덱 전체를 보여 준다. 이동 카드는 흐리게 "강화 불가 — 이동 카드"로 막는다. **버프 카드도 올릴 수치가 없어 막힌다**("강화 불가 — 올릴 수치가 없다", `upgradeBlock`).
   - 공격 · 가드 · 회복 · 기력 카드는 강화할 수 있다.
   - 고른 카드는 왼쪽에 크게 보인다. 범위는 9×5 격자(앞뒤 4칸 · 위아래 2줄)로 그린다.
2. **강화 종류**
   - **수치**: 카드의 주 수치를 같은 룰렛(0 / +5 / +10 / +15 / +20)으로 올린다.

     | 카드 | 오르는 값 | 표기 |
     | --- | --- | --- |
     | 공격 | 피해 | `DM` |
     | 가드 | 방어량(막는 양) | `BLOCK` |
     | 회복 | 회복량 | `HP+` |
     | 기력 | 얻는 기력(`gain`) | — (시안 표엔 없음 — 구현에서 정함) |

     버튼 이름도 카드에 맞춰 공격력 / 방어량 / 회복량으로 바뀐다.
   - **범위**: 걸린 숫자만큼 칸을 직접 고른다. 지금 고를 수 있는 칸을 주황 점선으로 미리 보여 준다. **범위가 없는 카드(가드 · 회복)는 이 버튼이 꺼지고** "범위가 없는 카드 — 수치만 강화할 수 있다"가 뜬다.
3. **룰렛**
   - 종류마다 다른 판을 쓴다. 둘 다 60칸으로 잘게 나눈다.

     | 판 | 값 | 확률 | 칸 수 |
     | --- | --- | --- | --- |
     | 공격력 | 0 / +5 / +10 / +15 / +20 | 10 / 25 / 30 / 25 / 10 % | 6 / 15 / 18 / 15 / 6 |
     | 범위 | 0 / 1 / 2 / 3 / 4 / 5 | 10 / 20 / 20 / 20 / 20 / 10 % | 6 / 12 / 12 / 12 / 12 / 6 |

   - 칸 배치는 숫자마다 원 둘레에 등간격으로 흩뿌린 뒤, 같은 숫자가 붙은 자리를 바꿔 없앤다(시안 코드 `seq`).
   - **결과를 먼저 가중 추첨하고**, 그 숫자 칸 중 하나를 골라 포인터 밑에 오도록 회전값을 계산한다. 그래서 그림과 확률이 항상 맞는다.
   - 연출: 7바퀴 + 목표 각도, 5.2초 `cubic-bezier(0.08,0.72,0.08,1)`. 도는 동안 포인터가 떨리고 테두리 전구 36개가 빨리 깜빡인다. 멈추면 가운데 원이 결과 숫자와 색으로 바뀐다.
4. **적용**
   - 0: "꽝". 강화 기회는 사용된다. 대장간이면 낸 80골드도 돌려받지 못한다.
   - 수치: `피해/방어량/회복량 + 값`(+5~+20). 바로 저장 화면으로 간다.
   - 범위: 아래 규칙대로 **N칸을 다 고르면** 저장 버튼이 켜진다.
5. **저장**: 강화된 카드를 보여 주고 지도로 나간다(대장간 · 낡은 대장간 모두 — 대장간은 한 번 강화하면 방문이 끝난다).

## 범위 고르기 규칙

- 범위는 지금처럼 `Offset { df, du }` 목록이다(df = 앞 +, du = 위 +).
- 편집 칸은 df −4…4, du −2…2다. 판이 6×4라 그 밖은 닿을 일이 없다.
- 고를 수 있는 칸은 **지금 범위 또는 나(0,0) 또는 이미 고른 칸에 8방향으로 붙은 빈 칸**이다. 고를수록 다음 칸이 열린다.
- **앞뒤 대칭으로 찍기**(토글): 켜면 한 번에 `(df,du)`와 `(−df,du)` 두 칸이 찍히고 남은 칸도 2개 줄어든다. 남은 칸이 1개면 한 칸만 찍힌다.
- 되돌리기는 마지막에 고른 칸부터 하나씩 뺀다. 고른 칸을 직접 눌러 빼는 것도 마지막 칸만 된다. 가운데 칸을 빼면 떨어진 칸이 생기기 때문이다. 초기화 버튼도 있다.
- 오른쪽 미리보기: 6×4 판에서 나는 2열이다. 원래 범위는 빨강, 새 칸은 주황으로 칠하고 "적 N명이 범위 안"을 보여 준다. 강화 후 카드도 함께 보여 준다(맞는 칸 수 전 → 후).
- 저장하면 `range = range.concat(picks)`다.

```ts
// 고를 수 있는 칸 판정 (시안 코드와 같다)
const canPick = (range: Offset[], picks: Offset[], c: Offset) => {
  const all = [...range, ...picks]
  if ((c.df === 0 && c.du === 0) || all.some((o) => o.df === c.df && o.du === c.du)) return false
  return [...all, { df: 0, du: 0 }].some((o) => Math.abs(o.df - c.df) <= 1 && Math.abs(o.du - c.du) <= 1)
}

// 룰렛 결과 (가중 추첨) — [값, %]
export const ROULETTE_VALUE = [[0, 10], [5, 25], [10, 30], [15, 25], [20, 10]] as const
export const ROULETTE_RANGE = [[0, 10], [1, 20], [2, 20], [3, 20], [4, 20], [5, 10]] as const
export const MAX_UPGRADE = 2
```

## 런 상태에 저장할 것

카드별 강화 기록이 필요하다: `{ cardId → { valueBonus: number, extraCells: Offset[], times: number } }`. `valueBonus`는 카드 종류에 따라 피해 · 가드 흡수량 · 회복량에 더한다. `times`는 최대 2다.
`runCard()`가 원본 카드에 이 기록을 덧씌운다(기존 `cardLevel` 자리).
