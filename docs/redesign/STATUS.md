# 상태이상 개편 — 기획 (2026-11-12 사용자 지정 · **아직 코드에 없음**)

> 지금 코드의 규칙은 CLAUDE.md §4 · `GAME_DESIGN.md` ⑥이다. 이 문서는 **바꿀 규칙**이고, 구현되면 그 둘을 같은 커밋에서 고친다.
> 상태이상을 하나씩 받아 적는다. 지금은 **중독**만 확정됐다. 2026-11-12 대조(PROGRESS 2-ter-b)가 출발점이다.

## 화면 — 상단 상태바 아래 아이콘 줄 (임시)

- 상태이상은 **상단 HUD 상태바(체력·기력) 아래**에 작은 아이콘으로 나란히 놓는다.
- 중첩되는 것(중독 · 힘 등)은 아이콘 옆에 **`×5`**처럼 중첩 수를 쓴다.
- 제대로 된 모양은 사용자가 **디자인 시안으로 다시 준다** — 그때까지는 비슷하게만.

## 1. 중독 (확정)

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹(중첩) 수 하나**로 센다. 걸 때마다 더해지고 **상한은 없다** — 오래 붙어 겹을 잘 쌓은 궁수가 이기는 게 맞다(사용자 확인) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다** → 5겹이면 5라운드가 끝나야 사라진다. 따로 "남은 라운드"는 없다 |
| 언제 아픈가 | 아래 "한 번"마다 **지금 겹 수 × 1** 피해 |
| 피해 성질 | 보호막 · 받는 피해 감소(유물 · 방어 강화)를 **관통**한다. 이 피해로 쓰러질 수 있다 |
| 걸리는 조건 | 지금과 같다 — 공격이 보호막·경감을 **실제로 뚫은 피해**가 있을 때만. 보호막이 다 받아 내면 안 걸린다 |
| 마지막 슬롯 | 3번 슬롯에서 1겹을 걸면 라운드 끝에 바로 줄어 사라진다(의도) |

예: 4겹일 때 움직이면 4 → 그 라운드 끝에 3겹 → 다음 라운드에 움직이면 3.
예: 3겹 · 보호막 20 · 체력 30에서 움직이면 체력 27(보호막 그대로). 그때 상대의 중독 카드(피해 10)가 보호막 20에 다 막히면 중독은 안 늘어난다.

### "한 번"으로 세는 것

| 일 | 아픈가 | 비고 |
| --- | --- | --- |
| 이동 카드 1장 | **한 번** | 두 칸 이동 · 빙판 미끄러짐까지 합쳐 한 번 |
| 공격 카드 1장 | **한 번** | 빗나가도. 이동공격(돌진·그림자 도약)도 움직임까지 합쳐 한 번 |
| 밀려나거나 끌려감 | **한 번** | 몇 칸이든 · 밀려서 빙판을 미끄러져도 한 번 |
| 수비 · 버프 · 회복 · **기력** 카드 | 안 아프다 | |
| 기절 · 빙결로 못 낸 카드 | 안 아프다 | 낸 적이 없다 |

### 거는 것 — 수치는 그대로, 뜻이 "N라운드" → "N겹"

| 무엇 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 카드 「독니 화살」(`arc-venom`) | 중독 2라운드 | **중독 2겹** |
| 카드 「독의 비」(`arc-rain`) | 중독 3라운드 + 독안개 | **중독 3겹** + 독안개 |
| 카드 「역병 화살」(`r-plaguebolt`) | 중독 2라운드 + 독안개 | **중독 2겹** + 독안개 |
| 카드 「역병의 물결」(`r-blightwave`) | 중독 2 · 화상 2 | **중독 2겹** · 화상(미정) |
| 카드 「쇠약의 파동」(`r-witherpulse`) | 중독 2라운드 | **중독 2겹** |
| 궁수 직업 패시브(독니 화살통) | 적중 시 중독 2라운드 | **없앤다**(사용자 지정 — 공격 +5 · 받는 피해 −2 · 체력은 그대로) |
| 항아리 이벤트 | 중독 2라운드를 안고 시작 | **중독 2겹**을 안고 시작 |
| 몬스터 | 뱀 · 박쥐 · 팬텀(독니 화살) · 뱀파이어(독의 비) | 카드를 따라 바뀐다 |

### 유물 — 새 문구 · 새 위력

| 유물 | 등급 | 새 효과 문구 | 훅 |
| --- | --- | --- | --- |
| 독약 플라스크 (`venomflask`) | 일반 | 공격으로 피해를 주면 **중독 1겹**을 묻힌다. | `poisonOnHit: 1` = 1겹 |
| 맹독 병 (`toxinvial`) | 희귀 | 피해를 주면 **중독 2겹**을 묻힌다. | `poisonOnHit: 2` |
| 재의 폐 (`ashlung`) | 영웅 | 피해를 주면 화상 2라운드 · **중독 1겹**을 함께 묻힌다. | |
| 부패의 왕관 (`rotcrown`) | 전설 | 피해를 주면 **중독 2겹** · 화상 2라운드를 함께 묻히고, 중독 · 화상 위력 +50%, 상태이상 상대에게 피해 +5. | |
| 동사의 저주 (`freezerot`) | 전설 | 전투당 세 번 빙결을 걸고, 피해를 주면 **중독 2겹** · 화상 2라운드를 묻힌다. | |
| 마녀의 안식일 (`sabbath`) | 전설 | 내가 중독을 걸 때 **1겹 더**, 화상은 1라운드 더 간다. | `poisonRoundBonus` → 걸 때마다 +1겹 |
| 사악한 절구 (`wickedmortar`) | 희귀 | 내가 거는 중독 · 화상 위력 +40%. | 아래 "위력 %" |
| 한파 (`coldsnap`) | 희귀 | 전투당 두 번 빙결을 걸고, 내가 거는 중독 · 화상 위력 +25%. | 〃 |
| 마녀의 탕약 (`witchbrew`) | 영웅 | 내가 거는 중독 · 화상 위력 +65%. | 〃 |

- **한 대에 여러 곳이 걸면 다 더한다**(카드 + 유물 + 안식일). 예: 독니 화살 2 + 맹독 병 2 + 안식일 1 = 5겹.
- **위력 %**: 중독 피해 = `round(겹 × (1 + %/100))` — **아플 때** 계산한다(겹이 하나의 수라 거는 순간에 박아 둘 곳이 없다). 거는 쪽(상대)의 유물을 본다. 예: 절구 +40% — 1겹 1 · 2겹 3 · 3겹 4 · 5겹 7.
- 「차가운 쇠」 · 「뼈 발라내기」 · 「사냥꾼의 앙심」 등 "상태이상 상대에게 +N"은 그대로(중독 1겹 이상이면 걸린 것).

### 밸런스

지금(겹당 3 · 최대 3겹 → 행동당 최대 9)과 크게 다르다. 궁수 직업 패시브 중독도 빠진다. **구현하면서 나중에 맞춘다**(사용자 지정) — 구현 직후 3시드 스윕 값을 PROGRESS에 남긴다.

### 구현할 곳 (다음 작업자용)

- `battle/types.ts` — 중독을 겹마다 한 칸 → **한 칸 + 겹 수**로(`STATUS_STACK_CAP` · `STATUS_MAX_ROUNDS`는 중독에서 빠진다). `POISON_TICK_DAMAGE` 3 → 겹당 1.
- `battle/engine.ts` — `applyStatus`(더하기) · `tickPoison`(행동 단위 한 번 · 이동공격 · 넉백 · 빙판을 한 번으로) · `tickStatuses`(중독은 겹 −1) · 위력 %를 틱 때 계산. 화상은 아직 옛 규칙이라 둘을 갈라야 한다.
- `game/relics.ts` — 문구 9개 · 궁수 직업 패시브 `poisonOnHit` 삭제. `data/roster.ts` 카드 설명 · `Passive` 주석. `runcards.ts` 카드 설명. `events.ts` 항아리 문구 · `runbattle.ts` 시작 중독.
- 화면 — `cardAbility.ts`(「중독 N겹」) · `FirstTip.tsx` · `BattleScreen` 상태 칩 → 상태바 아래 아이콘 줄 `×N`.
- `ai.ts` 중독 계산 · `scripts/checkhooks.ts` 불변식 · 시안 문구(`Relics` · `EventsQ` 등)는 따라간다.
- PvP는 보지 않는다(사용자 지정) — `ROSTER.passive`의 궁수 중독 1은 그대로 둔다.
