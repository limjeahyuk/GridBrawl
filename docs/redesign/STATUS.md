## 1. 중독 (확정 · **구현됨 2026-11-12**)

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹(중첩) 수 하나**로 센다. 걸 때마다 더해지고 **상한은 없다** — 오래 붙어 겹을 잘 쌓은 궁수가 이기는 게 맞다(사용자 확인) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다** → 5겹이면 5라운드가 끝나야 사라진다. 따로 "남은 라운드"는 없다 |
| 언제 아픈가 | 아래 "한 번"마다 **지금 겹 수 × 1** 피해 |
| 피해 성질 | 보호막 · 받는 피해 감소(유물 · 방어 강화)를 **관통**한다. 이 피해로 쓰러질 수 있다 |
| 걸리는 조건 | 지금과 같다 — 공격이 보호막·경감을 **실제로 뚫은 피해**가 있을 때만. 보호막이 다 받아 내면 안 걸린다 |
| 마지막 슬롯 | 3번 슬롯에서 1겹을 걸면 라운드 끝에 바로 줄어 사라진다(의도) |

예: 4겹일 때 움직이면 4 → 그 라운드 끝에 3겹 → 다음 라운드에 움직이면 3.
예: 3겹 · 보호막 20 · 체력 30에서 움직이면 체력 27(보호막 그대로). 그때 상대의 중독 카드(피해 10)가 보호막 20에 다 막히면 중독은 안 늘어난다.

### "한 번"으로 세는 것

| 일 | 아픈가 | 비고 |
| --- | --- | --- |
| 이동 카드 1장 | **한 번** | 두 칸 이동 · 빙판 미끄러짐까지 합쳐 한 번. 벽 · 바위 · 속박에 막혀 **한 칸도 못 움직이면 안 아프다**(사용자 확인) |
| 공격 카드 1장 | **한 번** | 빗나가도. 이동공격(돌진·그림자 도약)도 움직임까지 합쳐 한 번 |
| 밀려나거나 끌려감 | **한 번** | 몇 칸이든 · 밀려서 빙판을 미끄러져도 한 번. 처박혀 0칸이면 안 아프다 |
| 수비 · 버프 · 회복 · **기력** 카드 | 안 아프다 | |
| 기절 · 빙결로 못 낸 카드 | 안 아프다 | 낸 적이 없다 |

## 2. 화상 (확정 · 2026-11-12 사용자 지정)

**옛 규칙과 다르다** — 옛 화상은 "맞을 때마다 겹당 +5 · 보호막 관통"이었다. 새 화상은 **카드 공격의 피해를 % 늘리고, 늘어난 몫도 보호막이 막는다.**

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹 수 하나 · 상한 없음**(중독과 같다) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다**(중독과 같다) |
| 무엇을 하나 | **카드 공격**에 맞을 때 그 피해가 늘어난다 — **1겹 +10% · 2겹 +20% · 3겹 이상 +30%**(늘어나는 몫의 상한 30%). 겹은 계속 쌓여 오래 가지만 세기는 3겹에서 멈춘다 |
| 어디에 곱하나 | **보호막 전 카드 피해** = 카드 피해 + 공격 보너스(유물 · 직업) + 힘 + 공격 강화를 다 더한 값(지금 코드의 `raw`)에 곱하고 **반올림**한다 → 그 뒤에 보호막 · 받는 피해 감소 |
| 안 붙는 것 | 카드 공격이 아닌 피해 — 중독 · 출혈 몫 · 처박기 · 독안개 · 붕괴 |
| 피해 성질 | **보호막을 뚫지 못한다**(늘어난 몫까지 보호막이 받는다) |
| 걸리는 조건 | **체력이 닳아야** 걸린다(공격이 보호막 · 경감을 실제로 뚫은 피해가 있을 때만 — 지금과 같다) |
| 위력 % 유물 | **안 붙는다**(절구 · 한파 · 탕약 · 왕관은 중독 전용이 된다) |

예(사용자): 보호막 20 · 화상 3겹인 상대에게 피해 20 → `20 × 1.3` = **26** 이 들어간다 → 보호막 20이 받고 체력 −6.
예: 화상 1겹 · 피해 7 → `round(7.7)` = 8. 화상 5겹이어도 +30%.

지금 코드에 **없는** 상태이상이다(`StatusKind`에 `bleed` 추가 — id 임시).

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹 수 하나 · 상한 없음** |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다** |
| 언제 아픈가 | **카드 공격에 맞을 때마다** 추가 피해 — **1겹 5 · 2겹 10 · 3겹 이상 15**(한 번에 최대 15) |
| 안 아픈 것 | 카드 공격이 아닌 피해 — 중독 · 화상 · 처박기 · 독안개 · 붕괴(사용자 예: "중독 데미지에는 출혈 데미지가 들어가지 않는다") |
| 피해 성질 | **보호막을 뚫지 못한다** — 그 타격에 더해 **보호막이 같이 막고, 받는 피해 감소도 출혈 몫을 깎는다**. 감소는 카드 몫 + 출혈 몫을 **합친 한 타격에서 한 번만** 뺀다(사용자 확인) |
| "상태이상 상대에게 +N" | **출혈만 걸린 상대도 센다**(「차가운 쇠」 · 「뼈 발라내기」 · 「사냥꾼의 앙심」 · 왕관 — 사용자 확인) |
| 화상과 겹치면 | **화상 %는 출혈 몫에 안 붙는다**(카드 피해에만) |
| 위력 % 유물 | **안 붙는다** |
| 걸리는 조건 | **체력이 닳아야** 걸린다 |

예: 출혈 2겹 · 화상 1겹 · 피해 10 카드 → `round(10 × 1.1)` + 10 = 21 → 보호막 15가 받고 체력 −6.
예: 전사(받는 피해 감소 3) · 피해 10 · 출혈 2겹 → 10 + 10 − 3 = **17**(따로 빼서 14가 되지 않는다).

### 거는 것

**지금은 없다** — 출혈 카드 · 유물은 사용자가 추후 넣는다. 구현은 엔진 · 화면 바탕만 먼저 깔 수 있다.

### 그림

- 아이콘 줄의 출혈 아이콘이 필요하다(PROGRESS 2-bis T15).

### 구현할 곳 (다음 작업자용)

- `battle/types.ts` — `StatusKind`에 `bleed` · `CardDef.bleed` · 상수(겹당 5 · 상한 15).
- `battle/engine.ts` — 피격 계산(카드 공격만 · 화상 % 뒤에 더하고 보호막 · 경감 앞) · `applyStatus` · `tickStatuses` · `Step.bits`에 출혈 몫.
- 유물 훅(`bleedOnHit` 등 — 사용자가 유물을 정하면) · `scripts/checkhooks.ts` · `cardAbility.ts` · AI · 화면 아이콘.

## 4. 이동불가 상태이상 — 속박 · 기절 · 빙결 (확정 · 2026-11-12 사용자 지정)

**옛 규칙과 다르다** — 옛 셋은 "건 라운드만 · 라운드 끝에 사라짐 · 숫자는 뜻 없음(`>0`)"이었다. 새 규칙은 **숫자가 턴 수**이고 **라운드를 넘어간다.** 셋을 묶어 **이동불가 상태이상**이라 부른다.

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 숫자 | **건 턴 다음부터 N턴**(턴 = 슬롯 하나). 속박 1 = 건 턴 + **다음 턴까지**. 한 슬롯 안은 이동 → 수비 → 공격 순이라 공격으로 건 봉인이 닿을 땐 상대의 그 턴 이동 · 수비는 이미 끝났고, **같은 슬롯에 낸 상대 공격도 그대로 나간다**(지금처럼 트레이드 — 처박기만 예외, 아래). 그래서 숫자는 "다음 턴부터"를 센다(사용자 — "말이 1인데 지금의 2와 같은 효과") |
| 지속 | 턴이 끝날 때마다 1씩 줄고 0이면 풀린다. **라운드가 끝나도 이어진다** |
| 무엇을 하나 | 이전과 같다 — 기절 · 빙결 = 그 턴에 카드를 못 냄 · 속박 = 그 턴의 이동 카드만 무효 |
| 넘어간 봉인 | 다음 라운드로 넘어간 봉인 턴은 카드를 고를 때 **그 슬롯이 잠긴다**(카드를 못 넣는다) |
| 겹치기 | **속박 → 기절 → 빙결 순으로 위에 얹힌다**(아래 "겹치기" 표). 얹혀도 **가장 처음 걸린 봉인의 턴 수가 끝까지 간다** — 전체 길이는 안 늘어나고, 새 봉인의 턴은 남은 길이에서 잘린다 |
| 빙결 깨짐 | 빙결은 **카드 공격 · 처박기 · 붕괴 피해**를 받으면 풀린다(깨뜨린 타격 +5는 이전과 같다). **독안개 · 중독으로는 안 깨진다**. 빙결 중 속박 · 기절 · 빙결 공격을 맞으면 **빙결만 깨지고 새 봉인은 안 걸린다**. 깨져도 **밑에 깔린 기절 · 속박의 턴이 남았으면 그 상태로 돌아간다** |
| 처박기 | 넉백이 벽 · 바위에 막히면 **기절 1**(= 다음 턴까지 — 사용자 "딱 다음 턴까지만"). 칸당 5 피해 · 같은 슬롯 반격이 막히는 것(2026-11-10)은 그대로 |
| 걸리는 조건 · 전투당 횟수 | 이전과 같다(체력이 닳아야 걸림 · 유물 "전투당 N번") |

예: 1라운드 3턴에 내가 **기절 3** 성공(숫자가 "다음 턴부터"라 사용자가 처음 든 예보다 한 턴 길다)

| 때 | 나 | 적 |
| --- | --- | --- |
| 1라운드 3턴 | 공격 | 같은 슬롯 공격은 이미 나간다 · 기절 3 |
| (라운드 끝 — 기절은 이어진다 · 2라운드 세 슬롯이 잠긴 채 고른다) | | |
| 2라운드 1턴 | 공격 가능 | 못 냄 · 기절 2 |
| 2라운드 2턴 | 공격 가능 | 못 냄 · 기절 1 |
| 2라운드 3턴 | 공격 가능 | 못 냄 · 기절 0 → 풀림 |
| 3라운드 1턴 | 공격 가능 | 공격 가능 |

### 겹치기 (2026-11-12 사용자 확정)

| 이미 걸린 것(맨 위) | + 속박 | + 기절 | + 빙결 |
| --- | --- | --- | --- |
| 속박 | 안 걸림 | **걸림**(남은 길이까지) | **걸림**(남은 길이까지) |
| 기절 | 안 걸림 | 안 걸림 | **걸림**(남은 길이까지) |
| 빙결 | 안 걸림 · 빙결만 깨짐 | 안 걸림 · 빙결만 깨짐 | 안 걸림 · 빙결만 깨짐 |

- 예(사용자): **속박 3**인 상대를 **기절 1**로 → 속박 3 · 기절 1 — 기절이 먼저 끝나고 남은 턴은 속박.
- 예(사용자): **속박 1**인 상대를 **기절 3**으로 → **기절 1**(처음 걸린 속박의 길이에서 잘린다).
- 예(사용자): **속박 3**인 상대를 **빙결 1**로 → 속박 3 · 빙결 1. 그 1턴에 맞으면 빙결이 깨지며 +5를 받고, 안 맞으면 피해 없이 빙결이 끝난다 → 어느 쪽이든 **속박 2**로 이어진다.
- 예: **기절 3**인 상대를 **빙결 1**로 → 기절 3 · 빙결 1. 빙결이 깨지거나 끝나도 기절 턴이 남았으면 계속 기절이다.
- 봉인을 3번 슬롯에 넣어 다음 라운드 1턴을 잠그는 게 정석이 돼도 괜찮다(사용자 확인).

### 거는 것 — 카드 · 유물은 전부 1턴(= 다음 턴까지)

| 무엇 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 빙결 카드 3장 — 「서리 결계」(`mag-frost`) · 「서리 폭발」(`r-frostnova`) · 「심연의 낙인」(보스) | 그 라운드 빙결 | **빙결 1** |
| 기절 카드 6장 — 「대지 가르기」 · 「돌기둥 세우기」(전사) · 「석순 소환」(마법사) · 「뇌명의 지팡이」 · 「충격파」(런) · 「최후의 심판」(보스) | 그 라운드 기절 | **기절 1** |
| 속박 카드 5장 — 「가시 올가미」(궁수) · 「가시덩굴」 · 「종언의 만가」 · 「속박의 저주」(마법사) · 「혼백의 손아귀」(런) | 그 라운드 속박 | **속박 1** |

| 얽매는 뿌리(`grasproot`) | 속박이 다음 라운드까지 | **내가 거는 속박 +2턴**(임시 — 사용자가 추후 조정) |

| 처박기 | 그 라운드 기절 | **기절 1** |

### 구현할 곳 (다음 작업자용)

- `battle/types.ts` — 이동불가 셋은 `rounds` 대신 **남은 턴**(종류마다) + "처음 걸린 봉인이 끝나는 턴"(겹치기 상한). 맨 위 봉인 = 빙결 > 기절 > 속박 중 남은 것. `isRoundLock`의 "라운드 시작에 지운다" 전제가 깨진다(주석 · 이름).
- `battle/engine.ts` — 슬롯이 끝날 때마다 턴 −1 · `applyStatus`의 재부여 가드를 위 겹치기 규칙으로 · 빙결 깨짐(카드 공격 · 처박기 · 붕괴)이 같은 타격의 새 봉인을 막음 · 처박기 기절 1 · 연장 훅(`bindRoundBonus` 등)을 턴으로 · 넘어간 봉인 슬롯은 플랜에서 비움.
- 화면 — 카드 고를 때 **잠긴 슬롯**(지금 "이유 칩"은 런에서 뜰 일이 없던 죽은 UI) · 아이콘 줄에 남은 턴. `planAffordable`도 잠긴 슬롯을 빼고 본다.
- `cardAbility.ts`(「기절 1턴」) · 카드 · 유물 문구 · `checkhooks.ts`.
- **최고급 AI의 봉인기 대응은 이번에 보지 않는다**(사용자 — 추후 다시 조정). AI가 잠긴 슬롯을 비우는 것만 맞춘다.

## 5. 힘 · 버프 — 지금과 같다 (2026-11-12 사용자 확인)

| 무엇 | 규칙(바뀌지 않음) | 거는 것 |
| --- | --- | --- |
| 힘(`empower`) | **힘 N = 내 모든 공격 피해 +N**. 쓸 때마다 쌓이고 **전투 내내** 간다 | 「피의 각인」(`r-protocol`) +3 · 「울림의 파문」(`r-resonance`) +2 · 보스 「불씨 모으기」(화염군주) +2 |
| 공격 강화(`atkUp`) | 적힌 **라운드** 동안 내 공격 피해 +N. 다시 걸면 위력 · 지속 중 큰 쪽 | 「피의 맹세」 +7 · 「사냥꾼의 집중」 +6 · 「숫돌 갈기」 +5 · 「전투 문신」 +9 |
| 방어 강화(`defUp`) | 적힌 **라운드** 동안 받는 공격 피해 −N | 「불굴의 함성」 −5 · 「잿빛 장막」 −4 · 「혼백의 장막」 −5 · 「결속의 외침」 −4 |
| 무아지경(`freeCast`) | 적힌 **라운드** 동안 기력 소모 0 | 「무아지경」(마법사) · 「무아의 경지」(런) |

- 버프 지속은 **라운드** 그대로다(이동불가처럼 턴으로 바꾸지 않는다).
- 힘 · 공격 강화는 화상이 곱하는 "카드 피해"(`raw`)에 들어간다(2절).

- 힘 수치(지금 카드당 +2 · +3)는 사용자가 나중에 올릴 수 있다(+3 · +5 검토 — 2026-11-12).
