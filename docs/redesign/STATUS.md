# 상태이상 개편 — 기획 (2026-11-12 사용자 지정 · **아직 코드에 없음**)

> 지금 코드의 규칙은 CLAUDE.md §4 · `GAME_DESIGN.md` ⑥이다. 이 문서는 **바꿀 규칙**이고, 구현되면 그 둘을 같은 커밋에서 고친다.
> 상태이상을 하나씩 받아 적는다. **중독** 확정 · **화상**(새 규칙) · **출혈**(새 상태이상) 받는 중 — 미정 칸은 사용자 답 대기. 2026-11-12 대조(PROGRESS 2-ter-b)가 출발점이다.

## 화면 — 상단 상태바 아래 아이콘 줄 (임시)

- 상태이상은 **상단 HUD 상태바(체력·기력) 아래**에 작은 아이콘으로 나란히 놓는다.
- 중첩되는 것(중독 · 힘 등)은 아이콘 옆에 **`×5`**처럼 중첩 수를 쓴다.
- 제대로 된 모양은 사용자가 **디자인 시안으로 다시 준다** — 그때까지는 비슷하게만.

## 1. 중독 (확정)

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹(중첩) 수 하나**로 센다. 걸 때마다 더해지고 **상한은 없다** — 오래 붙어 겹을 잘 쌓은 궁수가 이기는 게 맞다(사용자 확인) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다** → 5겹이면 5라운드가 끝나야 사라진다. 따로 "남은 라운드"는 없다 |
| 언제 아픈가 | 아래 "한 번"마다 **지금 겹 수 × 1** 피해 |
| 피해 성질 | 보호막 · 받는 피해 감소(유물 · 방어 강화)를 **관통**한다. 이 피해로 쓰러질 수 있다 |
| 걸리는 조건 | 지금과 같다 — 공격이 보호막·경감을 **실제로 뚫은 피해**가 있을 때만. 보호막이 다 받아 내면 안 걸린다 |
| 마지막 슬롯 | 3번 슬롯에서 1겹을 걸면 라운드 끝에 바로 줄어 사라진다(의도) |

예: 4겹일 때 움직이면 4 → 그 라운드 끝에 3겹 → 다음 라운드에 움직이면 3.
예: 3겹 · 보호막 20 · 체력 30에서 움직이면 체력 27(보호막 그대로). 그때 상대의 중독 카드(피해 10)가 보호막 20에 다 막히면 중독은 안 늘어난다.

### "한 번"으로 세는 것

| 일 | 아픈가 | 비고 |
| --- | --- | --- |
| 이동 카드 1장 | **한 번** | 두 칸 이동 · 빙판 미끄러짐까지 합쳐 한 번. 벽 · 바위 · 속박에 막혀 **한 칸도 못 움직이면 안 아프다**(사용자 확인) |
| 공격 카드 1장 | **한 번** | 빗나가도. 이동공격(돌진·그림자 도약)도 움직임까지 합쳐 한 번 |
| 밀려나거나 끌려감 | **한 번** | 몇 칸이든 · 밀려서 빙판을 미끄러져도 한 번. 처박혀 0칸이면 안 아프다 |
| 수비 · 버프 · 회복 · **기력** 카드 | 안 아프다 | |
| 기절 · 빙결로 못 낸 카드 | 안 아프다 | 낸 적이 없다 |

### 유물 — 새 문구 · 새 위력

| 유물 | 등급 | 새 효과 문구 | 훅 |
| --- | --- | --- | --- |
| 독약 플라스크 (`venomflask`) | 일반 | 공격으로 피해를 주면 **중독 1겹**을 묻힌다. | `poisonOnHit: 1` = 1겹 |
| 맹독 병 (`toxinvial`) | 희귀 | 피해를 주면 **중독 2겹**을 묻힌다. | `poisonOnHit: 2` |
| 재의 폐 (`ashlung`) | 영웅 | 피해를 주면 화상 2라운드 · **중독 1겹**을 함께 묻힌다. | |
| 부패의 왕관 (`rotcrown`) | 전설 | 피해를 주면 **중독 2겹** · 화상 2라운드를 함께 묻히고, 중독 · 화상 위력 +50%, 상태이상 상대에게 피해 +5. | |
| 동사의 저주 (`freezerot`) | 전설 | 전투당 세 번 빙결을 걸고, 피해를 주면 **중독 2겹** · 화상 2라운드를 묻힌다. | |
| 마녀의 안식일 (`sabbath`) | 전설 | 내가 중독을 걸 때 **1겹 더**, 화상은 1라운드 더 간다. | `poisonRoundBonus` → 걸 때마다 +1겹 |
| 사악한 절구 (`wickedmortar`) | 희귀 | 내가 거는 중독 · 화상 위력 +40%. | 아래 "위력 %" |
| 한파 (`coldsnap`) | 희귀 | 전투당 두 번 빙결을 걸고, 내가 거는 중독 · 화상 위력 +25%. | 〃 |
| 마녀의 탕약 (`witchbrew`) | 영웅 | 내가 거는 중독 · 화상 위력 +65%. | 〃 |

- **한 대에 여러 곳이 걸면 다 더한다**(카드 + 유물 + 안식일 · 사용자 확인). 예: 독니 화살 2 + 맹독 병 2 + 안식일 1 = 5겹.
- **위력 %**: 중독 피해 = `round(겹 × (1 + %/100))` — **아플 때** 계산하고 반올림한다(사용자 확인 · 겹이 하나의 수라 거는 순간에 박아 둘 곳이 없다). 거는 쪽(상대)의 유물을 본다. 예: 절구 +40% — 1겹 1 · 2겹 3 · 3겹 4 · 5겹 7.
- 「차가운 쇠」 · 「뼈 발라내기」 · 「사냥꾼의 앙심」 등 "상태이상 상대에게 +N"은 그대로(중독 1겹 이상이면 걸린 것).

## 2. 화상 (받는 중 · 2026-11-12 사용자 설명)

**옛 규칙과 다르다** — 옛 화상은 "맞을 때마다 겹당 +5 · 보호막 관통"이었다. 새 화상은 **받는 피해를 % 늘리고, 보호막을 뚫지 못한다.**

### 규칙

| 항목 | 규칙 |
| --- | --- |
| 중첩 | **겹 수 하나 · 상한 없음**(중독과 같다) |
| 지속 | **라운드가 끝날 때마다 1겹씩 줄어든다**(중독과 같다) |
| 무엇을 하나 | 맞는 피해가 늘어난다 — **1겹 +10% · 2겹 +20% · 3겹 이상 +30%**(늘어나는 몫의 상한 30%). 겹은 계속 쌓여 오래 가지만 세기는 3겹에서 멈춘다 |
| 계산 | **반올림**(중독과 같은 방식) |
| 피해 성질 | **보호막을 뚫지 못한다** |
| 걸리는 조건 | **체력이 닳아야** 걸린다(공격이 보호막 · 경감을 실제로 뚫은 피해가 있을 때만 — 지금과 같다) |

예(가정 — 아래 미정 ①이 "보호막 전 카드 피해에 곱한다"일 때): 화상 2겹 · 피해 12 카드에 맞으면 `round(12 × 1.2)` = 14. 보호막 10이 있으면 체력 4. 피해 7 · 1겹이면 `round(7.7)` = 8.

### 미정 — 사용자 답 대기

| # | 무엇 | 메모 |
| --- | --- | --- |
| ① | 늘어나는 기준 피해 | 보호막 **전** 카드 피해(보호막이 늘어난 몫도 막는다)인가, 보호막 · 경감 **뒤** 체력에 들어가는 몫인가 |
| ② | 어떤 피해에 붙나 | 카드 공격만인가, 중독 · 출혈 · 처박기 · 독안개 · 붕괴에도인가 |
| ③ | 거는 양 | 카드 `burn: N` → **N겹**인가(중독처럼). 카드 + 유물이 함께 걸면 더하는가 |
| ④ | 마법사 직업 패시브 | 지금 "피해를 주면 화상 2라운드"(`burnOnHit: 2`) — 그대로 2겹 / 줄임 / 삭제(궁수 중독은 삭제했다) |
| ⑤ | 위력 % 유물 | 절구 +40 · 한파 +25 · 탕약 +65 · 왕관 +50이 화상에 무엇을 하나 — 겹당 % 증가(10 → 14) · 상한 30 증가 · 화상엔 안 붙음(중독 전용) |
| ⑥ | 불길 함정 | 지금 "들어서거나 라운드 끝에 서 있으면 화상 1R" → 그때마다 1겹인가 |
| ⑦ | 출혈과 겹치면 | 출혈 피해에도 화상 %가 붙나(아래 출혈 미정 ③과 같은 질문) |

| ① | 보호막 · 경감과의 순서 | 출혈 피해를 그 타격에 **더해** 보호막이 같이 막는가(보호막이 다 받으면 0). 받는 피해 감소(유물 · 방어 강화 · 전사 −3)도 출혈 몫을 깎는가 |
| ② | 막힌 공격 | 카드 공격이 보호막에 다 막혀도 출혈 몫은 따로 들어가는가(①에 따라) |
| ③ | 화상과 겹치면 | 화상 %가 출혈 몫에도 붙나 |
| ④ | 누가 거나 | 거는 카드 · 유물 · 몬스터가 **하나도 없다** — 어느 직업 · 몇 장 · 몇 겹 · 유물이 있나 |
| ⑤ | 위력 % 유물 | 절구 · 탕약 등이 출혈에도 붙나 |
| ⑥ | "상태이상 상대에게 +N" | 「차가운 쇠」 · 「뼈 발라내기」 · 「사냥꾼의 앙심」 · 왕관이 출혈 상대도 세나 |
| ⑦ | 이름 · 아이콘 | id `bleed`(임시). 아이콘 줄의 출혈 아이콘 필요 |

### 구현할 곳 (다음 작업자용 — 미정이 풀린 뒤)

- `battle/types.ts` — `StatusKind`에 `bleed` · `CardDef.bleed` · 상수(겹당 5 · 상한 15).
- `battle/engine.ts` — 피격 계산(카드 공격만) · `applyStatus` · `tickStatuses` · `Step.bits`에 출혈 몫.
- 유물 훅(`bleedOnHit` 등 — ④가 정해지면) · `scripts/checkhooks.ts` · `cardAbility.ts` · AI · 화면 아이콘.
